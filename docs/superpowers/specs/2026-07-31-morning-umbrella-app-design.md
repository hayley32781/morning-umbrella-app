# 아침 우산 알리미 — 설계 문서

날짜: 2026-07-31

## 배경 / 목적

사용자는 코딩 경험이 없는 UX/UI 디자이너로, 오늘 하루 안에 완성해서 발표해야 한다.
아침에 우산을 챙겨야 할지를 한눈에 알려주는 웹페이지를 만든다.

제약 조건:
- 하루 안에 끝낼 수 있는 아주 작은 범위
- 기능 3개 이하 (핵심 판단 로직 포함)
- 코드 없이도 이해할 수 있는 설계, 최종적으로 배포까지 완료

## 범위 (In Scope)

핵심 기능 1개 + 부가 기능 2개, 그리고 기능으로 세지 않는 스타일링 1개.

1. **우산 필요/불필요 표시** (핵심) — 큰 문구 + 아이콘으로 "우산 챙기세요 ☂️" 또는 "우산 필요없어요 ☀️" 표시
2. **위치 자동 감지** — 브라우저 Geolocation API로 사용자 현재 위치를 자동으로 가져와 해당 지역 날씨를 조회 (수동 지역 검색/선택 없음)
3. **오늘 최고/최저 기온 + 강수확률 숫자 표시** — 우산 결과 아래 보조 정보로 표시
4. (기능 예산에 포함하지 않음) **날씨 상태에 따른 배경/일러스트 스타일링** — 맑음/비/흐림에 따라 배경색이 바뀜. 순수 CSS 작업으로 엔지니어링 리스크가 낮아 별도 기능으로 세지 않음

## 범위 밖 (Out of Scope)

- 시간대별 강수확률 그래프/차트 (엔지니어링 리스크가 커서 오늘 안에 끝내기 어려움 — 제외)
- 지역 검색/선택 UI (위치 자동 감지로 대체)
- 여러 날짜(주간) 예보
- 자동 테스트 코드 (시간 관계상 생략, 수동 확인으로 대체)
- 기상청 공공데이터 API, OpenWeatherMap (Open-Meteo로 대체 결정)

## 기술 스택

- **순수 HTML/CSS/JS 단일 파일** (`index.html`). 빌드 도구 없음.
- 날씨 데이터: **Open-Meteo API** (`https://api.open-meteo.com/v1/forecast`)
  - API 키 발급/회원가입 불필요, 클라이언트에서 직접 fetch 가능
  - hourly 파라미터로 `precipitation_probability`, `temperature_2m`, `weathercode` 요청
- 위치: `navigator.geolocation.getCurrentPosition()`으로 위경도 획득 후 Open-Meteo에 전달

## 동작 흐름 (Data Flow)

1. 페이지 로드 시 브라우저가 위치 권한을 요청
2. 사용자가 허용하면 위경도를 획득
3. 위경도로 Open-Meteo API 호출 (오늘 날짜의 hourly 데이터 요청)
4. 응답에서 활동 시간대(오전 6시~오후 6시)의 시간별 강수확률만 추출
5. 판단 로직 실행 → 결과 계산
6. 결과 + 최고/최저 기온 + 강수확률 숫자 + 날씨별 배경 스타일을 화면에 렌더링

## 판단 로직

- 오전 6시~오후 6시 사이의 시간별 강수확률(`precipitation_probability`) 중 **최댓값이 40% 이상**이면 "우산 필요"로 판단
- 40%는 초기 기본값이며, 코드 내 상수로 분리해 추후 쉽게 조정 가능하게 작성

## 화면 구성 (UI)

한 페이지, 스크롤 없는 단일 화면 구성:

- 중앙: 큰 문구 — "우산 챙기세요 ☂️" / "우산 필요없어요 ☀️"
- 문구 하단: 작은 글씨로 오늘 최고/최저 기온, 강수확률 %
- 배경: 날씨 상태(맑음/비/흐림)에 따라 배경색 또는 이모지형 일러스트 변경

## 오류 처리

- 위치 권한 거부/실패 시 → "위치 정보가 필요해요" 안내 문구 + 다시 시도 버튼 표시
- API 호출 실패(네트워크 오류 등) 시 → "잠시 후 다시 시도해주세요" 안내 문구 표시
- 두 경우 모두 결과 영역은 비워두고 안내 문구로 대체 (에러로 인한 빈 화면/깨진 화면 방지)

## 검증 방법

- 자동 테스트 코드는 작성하지 않음 (시간 제약)
- 구현 완료 후 브라우저로 직접 열어 다음을 육안 확인:
  - 위치 허용 시 정상적으로 우산 결과가 표시되는지
  - 위치 거부 시 안내 문구가 표시되는지
  - 강수확률이 높은/낮은 지역(또는 임계값 임시 조정)에서 결과 문구가 올바르게 바뀌는지
  - 최고/최저 기온, 강수확률 숫자가 실제 값과 일치하는지

## 배포

- GitHub Pages를 통해 배포
- 완성된 `index.html`을 GitHub 저장소에 올리고 Pages 기능을 활성화하여 공개 URL 생성
